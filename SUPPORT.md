# Support

## Getting Help

**GitHub Issues**
For bugs or unexpected behavior, open an [issue](https://github.com/core-red-project/obfusku/issues). Use the bug report template and include enough context to reproduce the problem.

**Discord**
For questions, general discussion, or anything that isn't a bug — join the Sxnnyside Project community at [discord.gg/h3hhNY8VTE](https://discord.gg/h3hhNY8VTE).

**Email**
For anything that doesn't fit the channels above — `support.sxnnyside@sxnnysideproject.com`.

---

## Before Asking

- Check the [README](README.md) — installation and usage are documented there.
- Search existing [issues](https://github.com/core-red-project/obfusku/issues) before opening a new one.

---

## What This Isn't

This is not a priority support channel. Response times are not guaranteed.
For security vulnerabilities, see [SECURITY.md](SECURITY.md).
